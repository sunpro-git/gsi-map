Google 連携の設定（任意）

設定しなくても、地図・検索・ルート作成・高低差・GPX・ナビはすべて使えます。 Google の下絵地図とアプリ内ストリートビュー、Google ドライブへの保存を使う場合だけ必要です。 いまは「キャンセル」で閉じて構いません。

入力した値はこのブラウザの localStorage にのみ保存され、Google 以外へは送信されません。 Google Cloud コンソールで Maps JavaScript API と Google Drive API を有効化し、 API キーには HTTP リファラー制限を、OAuth クライアント ID（ウェブアプリケーション）には 「承認済みの JavaScript 生成元」にこのアプリの URL を設定してください。

Google ログインが必要です

ログインせずに保存すると、この端末にだけ保存されます。 パソコンやほかのスマホからは見られません。

設定

現在地を使いますか？

Google マップの座標を貼り付け

Google マップで位置を決め直したら、その地点を右クリック（スマホは長押し）→「座標をコピー」し、 ここに貼り付けてください。この地点にピンを立て直します。

緯度経度のほか、https://www.google.com/maps/@… 形式の URL、 度分秒（35°40'52.4"N 139°46'01.7"E）も読み取れます。
短縮 URL（maps.app.goo.gl）は展開できないため、「座標をコピー」をお使いください。

ルートに名前を付けて保存

Google ドライブに保存すると、マイドライブの MAP TOOL フォルダに GPX 形式で保存されます。 同じ名前のファイルがある場合は上書きします。
「アプリに送る」はスマホの共有シートを開きます。Zepp などファイルを受け取れるアプリを選ぶと、 入力した名前の GPX をそのまま渡せます（HTTPS 接続時のみ）。
